# Лабораторна робота №4: Наслідування та Поліморфізм

**Варіант:** 4 (Animal -> Dog -> Cat)

## Опис ієрархії
- **Animal**: базовий клас із полями імені та віку, віртуальним методом `MakeSound()` та методом `GetSpecies()`.
- **Dog**: похідний клас із додатковим полем `Breed`. Перевизначає `MakeSound()`, приховує `GetSpecies()` за допомогою `new` та має унікальний метод `Fetch()`.
- **Cat**: похідний клас із додатковим полем `IsIndoor`. Перевизначає `MakeSound()` та має унікальний метод `Purr()`.

## Контрольні запитання
1. **Наслідування** — механізм ООП для створення нових класів на основі існуючих. Приклад: Транспорт -> Автомобіль.
2. **base** — ключове слово для доступу до конструкторів чи методів батьківського класу.
3. **virtual / override** — реалізують динамічний поліморфізм (виклики методів за типом об'єкта в пам'яті).
4. **new** — приховує однойменний метод базового класу, результат виклику залежить від типу посилання.
