# Лабораторна робота №4: Наслідування та Поліморфізм

Варіант: 4 (Animal -> Dog -> Cat)

## Опис ієрархії
- **Animal**: базовий клас із полями імені та віку, віртуальним методом `MakeSound()` та методом `GetSpecies()`.
- **Dog**: похідний клас із додатковим полем `Breed`. Перевизначає `MakeSound()`, приховує `GetSpecies()` за допомогою `new` та має унікальний метод `Fetch()`.
- **Cat**: похідний клас із додатковим полем `IsIndoor`. Перевизначає `MakeSound()` та має унікальний метод `Purr()`.

## Контрольні запитання

1. Поясніть принцип наслідування в ООП. Наведіть приклад з реального світу.

 Наслідування дозволяє створити новий (похідний) клас на основі існуючого (базового), автоматично отримуючи його поля, властивості та методи. Приклад: Базовий клас "Транспортний засіб" має швидкість та метод "Рухатися". Похідні класи "Автомобіль" та "Літак" наслідують ці властивості, але додають свої унікальні (наприклад, літак додає метод "Летіти").

2. Для чого використовується ключове слово base? Наведіть приклади його застосування.

 `base` використовується для виклику функціоналу батьківського класу. 
Приклади:
1) Виклик конструктора батька: `public Car(...) : base(...) { }`. 
2) Виклик базового методу всередині перевизначеного: `public override void Move() { base.Move(); Console.WriteLine("Car is driving"); }`.

3. У чому полягає різниця між virtual та override? Як вони забезпечують поліморфізм?

 `virtual` ставиться у базовому класі, даючи методу дозвіл бути зміненим у майбутньому. `override` пишеться в похідному класі і фактично змінює код цього методу для даного нащадка. Завдяки цьому працює поліморфізм: коли програма бачить посилання типу `Vehicle`, але там лежить об'єкт `Car`, запуск віртуального методу виконає код саме з `override` в `Car`.

4. Коли варто використовувати модифікатор new для приховування члена базового класу, і які наслідки це має?

 Модифікатор `new` використовують, коли потрібно створити у похідному класі метод, назва якого випадково збіглася з методом батьківського класу, але вони логічно не пов'язані і поліморфізм не потрібен. Наслідок: метод базового класу приховується. Якщо звернутися до об'єкта через посилання батьківського класу — виконається старий базовий метод, а якщо через посилання поточного класу — новий метод з `new`.
